Aplikasi Android: CycleJournal — Kalender Haid & Jurnal Kesuburan
Package: com.app.cyclejournal • Terakhir diperbarui: Januari 2026

Ringkasan Jaminan Privasi (Zero-Knowledge): CycleJournal adalah aplikasi 100% offline-first. Seluruh catatan kesehatan reproduksi Anda disimpan secara lokal, terenkripsi (SQLCipher), di perangkat Anda. Kami tidak pernah memiliki akses ke isi data kesehatan Anda. Cadangan cloud opsional bersifat zero-knowledge: data dienkripsi AES-256-GCM di sisi klien dan server hanya menyimpan ciphertext.

1. Filosofi Zero-Knowledge

Seluruh data medis Anda — tanggal siklus, suhu basal tubuh (BBT), lendir serviks, skala nyeri (VAS 0–10), intensitas pendarahan, obat yang dikonsumsi, dan catatan klinis — hanya tersimpan di basis data terenkripsi di perangkat Anda. Tidak ada data kesehatan yang dikirim dalam bentuk teks terbuka ke server mana pun.

2. Izin Perangkat

Aplikasi hanya meminta izin yang mutlak diperlukan:

  • Biometrik (Fingerprint / Face): untuk membuka kunci aplikasi secara opsional.
  • Notifikasi: untuk pengingat pengukuran BBT dan peringatan siklus (H-2).
  • Alarm & Boot: untuk menjadwalkan pengingat klinis.
  • Akses Internet: hanya untuk cadangan cloud terenkripsi (opsional) dan verifikasi Google Play Billing.

3. Cadangan Cloud Terenkripsi (Optional, Zero-Knowledge)

Jika Anda mengaktifkan sinkronisasi bulanan ke Cloudflare D1, data diekspor menjadi JSON lalu dienkripsi di sisi klien menggunakan AES-256-GCM dengan kunci yang diturunkan dari PIN/passphrase Anda (PBKDF2, 100.000 iterasi). Server hanya menyimpan ciphertext dan hash integritas. Kami tidak memiliki kunci untuk membaca isi data kesehatan pengguna.

4. Identitas Anonim

Kami tidak meminta nama, email, atau nomor telepon. Aplikasi menghasilkan ID pasien anonim (format px-xxxxxxxxxxxx) yang menjadi kunci penyimpanan di cloud tanpa mengungkap identitas Anda. Anda dapat 100% menggunakan seluruh fitur tanpa mendaftarkan akun.

5. Iklan Non-Personalisasi

Pada paket gratis, kami menampilkan iklan non-personalisasi (Non-Personalized Ads) dengan npa: 1 sehingga GAID dan profil perilaku dinonaktifkan. Paket Pro menghilangkan seluruh komponen iklan. Lihat Kebijakan Privasi Google.

6. Google Play In-App Billing

Digunakan untuk pembelian lisensi Lifetime Pro (beli putus sekali). Seluruh transaksi keuangan diproses langsung oleh Google Play. Pengembang tidak pernah memiliki akses ke informasi keuangan Anda.

7. Keamanan & Kedaulatan Data

Basis data lokal dienkripsi dengan SQLCipher dan kunci master dilindungi oleh Android Keystore (envelope encryption). Karena data kesehatan tidak pernah disimpan dalam bentuk teks terbuka di server, tidak ada risiko kebocoran dari basis data terpusat. Keamanan data berada sepenuhnya dalam kendali Anda dan sistem keamanan perangkat fisik Anda.

8. Hak Penghapusan Total (GDPR & UU PDP)

Anda dapat menghapus seluruh data secara permanen dalam satu sentuhan (fitur “Hapus Semua Data”). Operasi ini akan: menghapus seluruh cadangan cloud di D1, membatalkan alarm & pekerjaan latar, menghancurkan basis data lokal terenkripsi, menghapus kunci enkripsi di Android Keystore, dan mereset aplikasi ke tahap awal.

9. Disclaimer Medis

CycleJournal adalah alat pencatatan klinis pribadi untuk referensi dokter kandungan (SpOG) dan bukan pengganti diagnosis medis profesional, bukan alat kontrasepsi, dan tidak boleh digunakan sebagai satu-satunya dasar keputusan kesehatan.
