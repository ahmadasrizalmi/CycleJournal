Kebijakan Privasi CycleJournal

Pengembang: Asri Digital (asridigital.com) Berlaku Efektif: 14 September 2026 Standar Kepatuhan: GDPR, UU PDP No. 27/2022, Google Play Health Policy

Komitmen Privasi Mutlak: CycleJournal dibangun dengan filosofi Zero-Knowledge. Seluruh catatan biomarker, suhu basal, dan siklus haid disimpan secara lokal terenkripsi di perangkat Anda. Pengembang maupun penyedia server Cloudflare tidak memiliki kunci untuk mendekripsi atau melihat data kesehatan Anda.

1. Pengantar & Identitas Pengendali Data

Kebijakan Privasi ini mengatur bagaimana Asri Digital ("kami", "pengembang") mengelola data dalam aplikasi seluler CycleJournal ("Aplikasi"). Kami menyadari sepenuhnya bahwa data kesehatan reproduksi adalah kategori data personal yang sangat sensitif dan berhak atas proteksi hukum tertinggi di bawah Undang-Undang Perlindungan Data Pribadi Indonesia (UU PDP No. 27/2022) dan General Data Protection Regulation Uni Eropa (GDPR Pasal 9).

2. Kategori Data yang Dicatat Pengguna

Aplikasi memungkinkan Anda untuk mencatat parameter kesehatan siklus dan biomarker fisik secara mandiri, yang mencakup:

  • Data Siklus Haid: Tanggal awal dan akhir menstruasi, intensitas aliran darah (spotting, ringan, sedang, deras).
  • Biomarker Kesuburan: Suhu Basal Tubuh (BBT) dalam derajat Celsius dan karakteristik lendir serviks (kering, krim, cair, putih telur).
  • Indikator Nyeri & Keluhan: Skor Visual Analog Scale (VAS 0–10), lokasi nyeri, konsumsi obat analgesik/pereda nyeri, dan catatan teks bebas.
  • Data Kredensial Keamanan: Kode PIN 4-digit (hanya disimpan dalam bentuk cryptographic hash SHA-256 lokal) dan Anonymous Recovery ID (berupa UUID anonim, contoh: px-7f9a2b1c4e0d).

3. Arsitektur Penyimpanan Lokal & Enkripsi Sisi Klien

CycleJournal beroperasi dengan paradigma 100% Offline-First:

  • Database SQLCipher: Berkas SQLite di memori internal perangkat Android dienkripsi menyeluruh dengan standar militer AES-256. Kunci database dihasilkan dari hardware enclave perangkat (Android Keystore TEE/StrongBox) sehingga tidak dapat diintip oleh aplikasi lain atau pihak ketiga pada perangkat yang telah di-root.
  • Nol Pembuatan Akun: Anda tidak diwajibkan untuk mendaftarkan nama, alamat email, nomor telepon, atau menghubungkan akun Google/Apple untuk menggunakan aplikasi.

4. Mekanisme Cadangan Cloud Zero-Knowledge

Aplikasi menyediakan fitur opsional cadangan cloud 1x sebulan ke Cloudflare D1 sebagai mekanisme disaster recovery:

  • Enkripsi Sebelum Transmisi: Data lokal diekspor menjadi payload JSON, lalu dienkripsi di perangkat Anda menggunakan algoritma AES-256-GCM dengan kunci derivasi PBKDF2 (100.000 iterasi) berbasis PIN pengguna.
  • Peran Server: Cloudflare Workers dan Cloudflare D1 hanya menerima dan menyimpan ciphertext blob buram dan hash SHA-256 untuk validasi integritas. Server sama sekali tidak memegang kunci privat atau passphrase pengguna.

5. Kebijakan Iklan & Pelacak Pihak Ketiga

  • Nol SDK Analitik Perilaku: Kami tidak menyematkan Firebase Analytics, AppsFlyer, Facebook SDK, atau alat pelacak perilaku pengguna lainnya.
  • Iklan Non-Personal (Tingkat Gratis): Pada versi gratis, iklan spanduk disajikan melalui Google AdMob dengan parameter wajib npa=1 (Non-Personalized Ads). Parameter ini melarang Google menggunakan Google Advertising ID (GAID) atau melacak profil minat Anda. Data kesehatan tidak pernah dibagikan kepada jaringan periklanan.
  • Versi Pro Beli Putus: Pengguna versi Lifetime Pro menikmati aplikasi yang 100% bebas iklan dengan pemutusan total (hard kill-switch) terhadap seluruh modul iklan.

6. Hak Subjek Data & Penghapusan Permanen (Nuke Option)

Sesuai GDPR dan UU PDP, Anda memiliki hak penuh atas data Anda:

  • Hak Akses & Portabilitas: Anda dapat mengekspor seluruh basis data ke berkas CSV standar Excel atau dokumen PDF SpOG kapan pun secara luring.
  • Hak untuk Dilupakan (Right to be Forgotten): Aplikasi menyediakan fitur "Zona Bahaya / Hapus Semua Data" di menu Pengaturan. Mengetikkan konfirmasi "HAPUS" akan:
    1. Mengirimkan instruksi HTTP DELETE ke Cloudflare Worker untuk memusnahkan ciphertext di D1.
    2. Menutup dan menghapus seluruh berkas database SQLCipher lokal.
    3. Menghapus semua file laporan PDF/CSV di cache.
    4. Memusnahkan master key di Android Keystore dan mereset aplikasi ke keadaan awal.

7. Penafian Medis Resmi (Medical Disclaimer)

CycleJournal adalah sarana pencatatan mandiri untuk membantu telaah konsultasi dengan dokter spesialis kandungan (SpOG/OB-GYN) berdasarkan klasifikasi siklus FIGO. Aplikasi ini bukan merupakan alat diagnosis medis mandiri, perangkat medis bersertifikasi, maupun pengganti metode kontrasepsi klinis. Keputusan klinis dan terapi obat wajib dikonsultasikan dengan tenaga medis berwenang.
