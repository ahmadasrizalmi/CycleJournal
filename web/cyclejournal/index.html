Laporan PDF Siap SpOG (1-Halaman A4)

Dokter kandungan enggan membaca tangkapan layar ponsel yang berantakan. Ekspor laporan klinis monokrom dengan ringkasan metrik FIGO, deviasi standar siklus, grafik VAS nyeri, dan area tanda tangan dokter.

Deteksi Anomali Berstandar FIGO

Rule engine otomatis mendeteksi tanda bahaya medis: siklus memanjang (>38 hari / oligomenorea), siklus pendek (<24 hari), perdarahan berkepanjangan (>8 hari), pendarahan di luar siklus, dan dismenore hebat (VAS ≥ 7).

Metode Sintotermal & Suhu Basal (BBT)

Konfirmasi ovulasi presisi tinggi menggunakan aturan klinis 3-over-6: mendeteksi kenaikan suhu basal ≥0,2°C yang bertahan 3 hari di atas garis dasar, dikorelasikan dengan hari lendir serviks elastis (egg-white).

Portabilitas Data & Nuke Option

Data sepenuhnya milik Anda. Ekspor seluruh riwayat ke CSV berstandar RFC 4180 dengan UTF-8 BOM untuk Excel kapan pun, atau musnahkan seluruh data lokal dan cloud dalam satu sentuhan (Zona Bahaya GDPR).

Privasi Mutlak Klien

Zero-Knowledge Architecture

Data kesehatan reproduksi adalah rahasia paling intim. Server tidak pernah memegang kunci untuk membaca isi data Anda.

  • Enkripsi SQLCipher: Berkas SQLite di memori ponsel dienkripsi penuh dengan AES-256 via Android Keystore hardware enclave.
  • Backup Ciphertext Blob: Data dienkripsi di ponsel dengan PBKDF2 (100.000 iterasi) + AES-GCM sebelum dikirim ke Cloudflare D1.
  • Nol Akun & Nol Pelacak: Tanpa login Google/Apple, tanpa nama, tanpa nomor HP, dan tanpa SDK analitik pihak ketiga.

Format Payload Cloudflare D1 

{
  "user_id": "px-7f9a2b1c4e0d",
  "backup_month": "2026-09",
  "cipher_payload": "7B2mF...[AES-256-GCM]...",
  "payload_hash": "sha256_checksum"
}

Server hanya menyimpan ciphertext buram. Tanpa passphrase Anda, tidak ada pihak yang dapat mendekripsi data ini.
